# 📱 iOS 灵感站配置（v2 弹窗版）

> **新流程**（替代剪贴板/自动化方案）：
> 1. 小红书看到喜欢的 → 分享 → **保存图片**（到相册）
> 2. iPhone 主屏 → **点 Shortcut widget**
> 3. **弹出对话框** → 填图片链接（**可空**）→ 完成
> 4. Shortcut 拿"最新一张照片"+ 你填的 URL → 自动上传 → AI 分类
>
> **比之前稳**：链接是**显式填**的，不会忘、不会装错、不会跟剪贴板里别的东西冲突。

## 第 1 步：改造 Shortcut（5 分钟）

打开「快捷指令」App → 「我的快捷指令」tab → **点「保存到灵感站」**进入编辑。

### 1.1 删掉「获取剪贴板」动作

每个动作右边都有个 `×` 圆圈 → **点「📋 获取剪贴板」那个动作的 ×** → 选「删除」。

### 1.2 加新动作「要求输入」

1. 页面下方「搜索操作」 → 输入 **`要求输入`** 或 **`Ask`** 或 **`输入`**
2. 选 **「要求输入」**（带 💬 对话框图标的）
3. 配置：
   - **提示**：`图片链接（可空）`
   - **输入类型**：`文本`
   - **默认输入**：留空
   - **多行输入**：关闭

> 这个动作每次跑 Shortcut 都会弹一个输入框让你填。**不填直接点完成**也 OK（视为不存链接）。

### 1.3 改 URL 字段的值

JSON 请求体里：
1. 找到 `url` 字段
2. **点值字段**（现在显示「📋 剪贴板」）→ 弹出变量菜单
3. 选 **「📝 要求输入」**（蓝色魔法变量）—— **不是剪贴板，是要求输入**

### 1.4 改 imageBase64 字段的值

1. 找到 `imageBase64` 字段
2. **点值字段**（现在显示「⚡输入快捷指令的信息」）→ 弹出变量菜单
3. 选 **「🖼 获取最新照片」**（在「照片」类目下）

> 如果菜单里找不到「获取最新照片」：
> - 先在 Shortcut 主体里**加一个「获取最新照片」动作**（搜"最新照片"）
> - 然后再让 imageBase64 字段值选这个动作的输出

### 1.5 source 字段不用改

保持 `album-automation` 即可。

### 1.6 关闭「从 App 接收」

顶部那个「从『App 和其他 18 个』接收」：
1. **点蓝色字**「App 和其他 18 个」
2. 弹详细页 → **把所有勾全关**（或点「无」）
3. 这样 Shortcut **不会出现在分享面板**——只在主屏 widget 触发

### 1.7 保存

点右上角「完成」。

## 第 2 步：主屏 widget（已有则跳过）

> 如果你之前已经加过「保存到灵感站」 widget，**跳过这步**。

1. 回 iPhone 主屏 → **长按空白处**（图标晃动）
2. 点左上角 `+` → 搜 **「快捷指令」** → 选 widget → 选**小尺寸** → 「添加 widget」
3. **长按 widget** → 「编辑快捷指令」→ 选 **「保存到灵感站」**
4. 点完成

## 第 3 步：测试

### 3.1 在小红书保存图片

1. 打开小红书 → 找一条喜欢的笔记
2. **分享 → 保存图片**（不用复制链接！直接保存图片就行）
3. iPhone 弹出"已保存到照片"提示

### 3.2 点 widget 触发

1. **iPhone 上滑回主屏**
2. **等 1-2 秒**（让 iOS 把图加到"最近添加"相簿）
3. **点主屏「保存到灵感站」widget**

### 3.3 弹窗填链接

iOS 弹出对话框：
```
┌─────────────────────────────┐
│  图片链接（可空）              │
│  ┌─────────────────────┐   │
│  │                      │   │  ← 这里可填可不填
│  └─────────────────────┘   │
│                             │
│       [取消]      [完成]    │  ← 点完成
└─────────────────────────────┘
```

- **想存链接** → 粘贴小红书链接（提前在小红书点"复制链接"）→ 完成
- **懒得存** → 直接点完成（不填）

### 3.4 看通知 + 网页

- 通知 ✨ 灵感已保存 弹出
- 电脑浏览器 `http://localhost:8888/inspirations` 刷新
- 看到新记录：**带图、已分类、链接（如果有）**

## 🧪 故障排查

- **通知出现但灵感站没记录** → 看 `tail -f /tmp/netlify-dev.log` 找错误；检查 Shortcut 的 URL 是不是最新的 localtunnel 地址
- **弹窗没出来** → 检查「要求输入」动作配置（提示、输入类型）
- **点 widget 报"没有照片"** → 等 3 秒再点；或者在 Shortcut 里加一个「等待 2 秒」动作在「获取最新照片」之前
- **图片传不上去** → 看 Shortcut 跑的时候通知里有没有"响应内容"——会有错误信息
- **localtunnel 经常掉** → 部署到 Netlify（1 credit，URL 永远不变）—— 找我帮你搞

## 📋 Shortcut 最终结构

```
📝 要求输入（图链接）           ← 弹窗让你填（可空）
🌐 获取 URL 内容（POST + JSON）
   ├─ url: 📝 要求输入
   ├─ imageBase64: 🖼 获取最新照片
   └─ source: album-automation
🔔 显示通知
   └─ 标题: ✨ 灵感已保存
```

后端请求体长这样：
```json
{
  "url": "<你填的链接>",
  "imageBase64": "<最新一张照片的 base64>",
  "source": "album-automation"
}
```

后端会智能处理：
- `url` 不像 URL → 自动忽略，只存图
- `url` 是小红书深链（`xhsdiscover://...`）→ 自动转成 `https://www.xiaohongshu.com/explore/xxx`
- 剪贴板/格式问题 → 不报错，跳过 URL 字段
